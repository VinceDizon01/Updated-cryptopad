THE MATH BEHIND THE MARK

How ElGamal works

×

ElGamal uses a public key to establish a shared secret with a fresh random value. CryptoPad then derives an AES key and uses authenticated encryption for the note content.

  1. 01

    Key generation

    Choose private x and publish y = gˣ mod p.

  2. 02

    ElGamal encapsulation

    Choose fresh random k; compute c₁ = gᵏ mod p and shared secret yᵏ mod p.

  3. 03

    Hybrid encryption

    Derive an AES-256 key with HKDF-SHA256, then encrypt the message using AES-GCM.

  4. 04

    Decryption

    The private key computes c₁ˣ mod p to recreate the shared secret and decrypt/authenticate the message.

Educational prototype only. Use a vetted, standardized protocol and security review for real sensitive information.
